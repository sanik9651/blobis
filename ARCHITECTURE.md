# Архитектура Blobis Exchange

## Обзор системы

Blobis Exchange — это полнофункциональный DeFi-симулятор, построенный на React с использованием реальной математики автоматизированных маркет-мейкеров (AMM).

## Ключевые компоненты

### 1. Hooks (Бизнес-логика)

#### `useMarket.js` - Движок биржи
**Ответственность:**
- Управление пулами ликвидности (BC/$BLOB)
- Расчет цен по формуле x*y=k
- Исполнение market и limit ордеров
- Генерация OHLC свечей
- История сделок

**Ключевые функции:**
```javascript
getCurrentPrice()           // Текущая цена = poolBC / poolBLOB
calculateSlippage()         // Расчет проскальзывания
executeMarketOrder()        // Мгновенное исполнение
placeLimitOrder()          // Размещение лимитного ордера
checkLimitOrders()         // Автоматическое исполнение лимитов
```

**Математика:**
```
k = poolBC * poolBLOB = константа
При покупке: newPoolBC = poolBC + amountIn * 0.997
             newPoolBLOB = k / newPoolBC
             amountOut = poolBLOB - newPoolBLOB
```

#### `useMining.js` - Система майнинга
**Ответственность:**
- Управление апгрейдами
- Расчет пассивного дохода
- Офлайн-заработок (до 4 часов)

**Апгрейды:**
- Click Power: +1 BC за клик
- CPU Miner: +0.5 BC/s
- GPU Rig: +5 BC/s
- ASIC Miner: +25 BC/s
- Mining Farm: +150 BC/s
- Quantum Miner: +1000 BC/s

**Формула стоимости:**
```
cost = baseCost * (multiplier ^ level)
```

#### `useBalance.js` - Управление балансами
**Ответственность:**
- Единый источник истины для BC и $BLOB
- Атомарные операции add/deduct
- Синхронизация между майнингом и торговлей

### 2. Components (UI)

#### `TradingTerminal.jsx` - Главный контейнер
Координирует все подкомпоненты, управляет переключением вкладок Mining/Trading.

#### `CandlestickChart.jsx` - График OHLC
**Технологии:** Canvas API, requestAnimationFrame

**Особенности:**
- Рендеринг японских свечей
- Динамическое обновление текущей свечи
- Индикатор объема
- Hover-подсказки с OHLC данными

**Оптимизация:**
- Использование requestAnimationFrame для плавности
- Кэширование расчетов
- Ограничение истории (500 свечей)

#### `OrderBook.jsx` - Стакан заявок
Визуализация глубины рынка с цветовой индикацией bid/ask.

#### `TradeHistory.jsx` - Лента сделок
Time & Sales в реальном времени.

#### `TradingPanel.jsx` - Панель торговли
**Функции:**
- Переключение Market/Limit
- Расчет preview сделки
- Валидация балансов
- Отображение slippage

#### `MiningInterface.jsx` - Интерфейс майнинга
**Функции:**
- Кликер с анимацией частиц
- Сетка апгрейдов
- Статистика дохода

## Математические гарантии

### AMM Инварианты:
1. **Постоянный продукт:** `k = poolBC * poolBLOB` всегда сохраняется
2. **Комиссия:** 0.3% от каждой сделки идет в пул
3. **Slippage:** Автоматически растет с размером ордера
4. **Цена:** Всегда определяется соотношением резервов

### Защита от эксплойтов:
- Невозможно создать BC из воздуха (только майнинг)
- Невозможно создать $BLOB из воздуха (только покупка)
- Все операции атомарны через useBalance
- Валидация балансов перед каждой операцией

## Производительность

### Оптимизации:
1. **Canvas рендеринг:** requestAnimationFrame вместо setInterval
2. **Свечи:** Ограничение истории до 500 элементов
3. **Сделки:** Хранение только последних 100
4. **Order Book:** Автоматическая очистка исполненных ордеров
5. **localStorage:** Дебаунс записи через useEffect

### Метрики:
- Рендеринг графика: ~16ms (60 FPS)
- Исполнение сделки: <1ms
- Обновление свечи: <1ms

## Расширяемость

### Добавление новых фич:

**Новый индикатор (RSI):**
1. Добавить расчет в `useMarket.js`
2. Создать компонент `RSIIndicator.jsx`
3. Интегрировать в `CandlestickChart.jsx`

**Новый апгрейд:**
1. Добавить в `UPGRADES` объект в `useMining.js`
2. UI автоматически подхватит изменения

**Firebase интеграция:**
1. Создать `useFirebase.js` hook
2. Заменить localStorage на Firestore
3. Добавить real-time listeners
