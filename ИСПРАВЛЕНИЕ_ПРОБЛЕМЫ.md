# 🔧 Инструкция по исправлению проблемы с ботом

## Что было сломано:

1. ❌ Неправильный URL в переменных окружения: `https://blobis.onrender.com` вместо `https://blobis-gqla.onrender.com`
2. ❌ Отсутствовала переменная `WEBHOOK_URL` 
3. ❌ Двойная инициализация `application` в коде бота

## Что исправлено в коде:

✅ Убрана двойная инициализация в `telegram_bot.py:94`
✅ Обновлён `render.yaml` с правильными URL

## ⚠️ ЧТО НУЖНО СДЕЛАТЬ ВРУЧНУЮ:

### Шаг 1: Обновите переменные окружения на Render

Откройте: **https://dashboard.render.com/web/srv-d7rg9qugvqtc73bfq5i0/env**

Найдите и измените:

1. **WEBAPP_URL**
   - Старое значение: `https://blobis.onrender.com`
   - Новое значение: `https://blobis-gqla.onrender.com`

2. **WEBHOOK_URL** (если её нет - добавьте)
   - Нажмите "Add Environment Variable"
   - Key: `WEBHOOK_URL`
   - Value: `https://blobis-gqla.onrender.com/webhook`

3. Нажмите **"Save Changes"**

### Шаг 2: Дождитесь редеплоя

Render автоматически начнёт редеплой (3-5 минут). Следите за логами:
**https://dashboard.render.com/web/srv-d7rg9qugvqtc73bfq5i0/logs**

### Шаг 3: Проверьте работу

В логах должно появиться:
```
Setting webhook for bot to https://blobis-gqla.onrender.com/webhook
🤖 Blobis Bot is configured for webhooks.
Database initialized successfully
```

Затем откройте бота в Telegram и отправьте `/start`

## Альтернативный способ (через API):

Если у вас есть Render API ключ, выполните:

```bash
export RENDER_API_KEY='your_api_key_here'
./update_render_env.sh
```

API ключ можно получить здесь: https://dashboard.render.com/u/settings#api-keys

## Почему это произошло?

Render.com не обновляет переменные окружения автоматически из `render.yaml` для уже существующих сервисов. Изменения в `render.yaml` применяются только при создании нового сервиса.
