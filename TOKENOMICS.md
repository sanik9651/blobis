# 🪙 Токеномика Blobis

## Текущая реализация

Сейчас в проекте используется **симулятор DeFi** с виртуальными токенами:

### Токены
- **BC (Blobis Coin)** - основная валюта, добывается майнингом
- **$BLOB** - торговый токен, покупается/продается через AMM

### AMM (Automated Market Maker)
Используется формула **Constant Product** (как в Uniswap):
```
x * y = k
```
- `x` = количество BC в пуле (1,000,000 начально)
- `y` = количество $BLOB в пуле (10,000 начально)
- `k` = константа ликвидности

### Особенности
- ✅ Реалистичная математика DeFi
- ✅ Slippage при больших сделках
- ✅ Комиссия 0.3% (как в Uniswap)
- ✅ Сохранение состояния в Firebase
- ❌ НЕ настоящий блокчейн токен

## Варианты интеграции реального токена

### Вариант 1: TON Blockchain (Рекомендуется для Telegram)
**Плюсы:**
- Нативная интеграция с Telegram
- TON Connect для кошельков
- Низкие комиссии (~0.01 TON)
- Быстрые транзакции (5 сек)

**Минусы:**
- Требуется разработка смарт-контракта
- Нужна ликвидность для DEX
- Сложность интеграции

**Стоимость запуска:** ~$500-1000 (деплой контракта + начальная ликвидность)

### Вариант 2: Solana (Pump.fun)
**Плюсы:**
- Простой запуск токена через Pump.fun
- Автоматический листинг на Raydium
- Низкие комиссии
- Большая аудитория

**Минусы:**
- Нет прямой интеграции с Telegram
- Нужен внешний кошелек (Phantom)
- Высокая конкуренция

**Стоимость запуска:** ~$100-200

### Вариант 3: Base/Polygon (EVM)
**Плюсы:**
- Совместимость с Ethereum экосистемой
- Много готовых инструментов
- Низкие комиссии на L2

**Минусы:**
- Сложная интеграция в Telegram Mini App
- Нужен Web3 кошелек
- Дороже чем TON

**Стоимость запуска:** ~$300-500

### Вариант 4: Гибридный подход (Рекомендуется)
**Концепция:**
1. Игроки майнят BC в игре (симулятор)
2. BC можно обменять на реальный $BLOB токен через bridge
3. $BLOB торгуется на реальном DEX (TON/Solana)

**Плюсы:**
- Лучший UX (не нужен кошелек для игры)
- Реальная ценность токена
- Контроль над игровой экономикой
- Защита от ботов (bridge с KYC)

**Минусы:**
- Сложная архитектура
- Нужен backend для bridge
- Регуляторные риски

**Стоимость запуска:** ~$1000-2000

## Рекомендация

Для **MVP и тестирования** - оставить текущий симулятор.

Для **продакшена с монетизацией**:
1. **Запустить токен на TON** через TON Jetton
2. **Создать bridge** BC → $BLOB (1000 BC = 1 $BLOB)
3. **Добавить ликвидность** на DeDust/STON.fi
4. **Интегрировать TON Connect** для вывода
